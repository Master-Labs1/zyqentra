# FAQ

**Do I need an account?** Yes. Docs and pricing are public; funds and keys require a RealMailPro account.

**When can I create API keys?** After your first verified deposit of at least $10. Keys stay unlocked if your balance later reaches zero.

**Are failed requests charged?** No. Credits for failed billable calls are returned immediately.

**How do deposit bonuses work?** Each deposit gets its own tier's bonus: $10 → 5%, $100 → 10%, $250 → 20%, $500 → 30%, $1,000 → 40%, $5,000 → 50%, $10,000 → 60%, $15,000 → 70%.

**Which mailboxes can I create?** Gmail.com + Alias, Outlook.com + Alias, Gmail.com Original, Outlook.com Original. Inboxes expire after 10 minutes.

**Are there webhooks?** None are published. Poll the inbox.

**Are the SDKs on npm or PyPI?** Not yet. Install from source in this repository.

**Is RealMailPro open source?** No. Only the SDKs, examples and docs in this repository are MIT-licensed. The RealMailPro service and backend are proprietary.
