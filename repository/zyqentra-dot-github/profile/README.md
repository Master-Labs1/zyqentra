### Zyqentra — *Build beyond limits.*

Developer documentation, SDKs and tooling for the **[RealMailPro](https://realmailpro.online)** API.

</div>

**What we do** — Zyqentra maintains the independent developer kit for RealMailPro: temporary Gmail.com & Outlook.com inboxes and OTP reading for end-to-end tests and QA on accounts you own.

**Relationship with RealMailPro** — RealMailPro operates the API service. Zyqentra publishes documentation and client code written from RealMailPro's public docs. The RealMailPro service and backend are proprietary and not part of our repositories.

| Resource | Where |
| --- | --- |
| API documentation | [realmailpro.online/docs](https://realmailpro.online/docs) |
| Developer kit (OpenAPI, Postman, examples) | `realmailpro-api` — coming soon |
| TypeScript SDK | pre-release, build from source |
| Python SDK | pre-release, install from source |

**Support** — account and billing: [realmailpro.online](https://realmailpro.online) · security: support@realmailpro.online
**Contributing** — corrections welcome; every API claim must link to RealMailPro's published docs.
